# PayYourDept
Программа для учёта и управления долгами

О проекте

PayYourDept — это приложение, разработанное на языке программирования C# с использованием технологии Windows Forms в среде Visual Studio 2022.

Основная цель проекта — создание удобной программы, которая помогает пользователю вести учёт долгов, хранить информацию о задолженностях и управлять ими.

Основные возможности

- Добавление новых долгов.
- Удаление существующих записей.
- Учёт информации о задолженностях.
- Управление списком долгов.
- Удобный и понятный пользовательский интерфейс.

Используемые технологии

- C# — основной язык программирования.
- Windows Forms — создание графического интерфейса.
- Visual Studio 2022 — среда разработки.
- GitHub — хранение исходного кода проекта.

Интерфейс

Приложение имеет тёмное оформление с использованием чёрных и фиолетовых оттенков.

Интерфейс разработан с целью сделать взаимодействие с программой простым и понятным.

Цель разработки

Данный проект создан в рамках дипломной работы IT Step.

В процессе разработки были использованы знания программирования на C#, создания графических интерфейсов и работы с Windows Forms.
